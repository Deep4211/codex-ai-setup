This repository uses the Codex-native Vyapar AI setup. Codex configuration is independent from every other AI client in the repository.

## Working agreement

- Read the nearest `AGENTS.md` or `AGENTS.override.md` before changing files.
- Preserve existing work and keep changes within the user’s requested scope.
- Inspect the relevant implementation and tests before editing.
- Prefer focused searches and the repository’s established scripts.
- Verify changes in proportion to risk and report anything that could not be run.
- Never read, print, or commit secrets from environment files or credential stores.
- Ask before destructive operations, production changes, credential changes, or broad permission changes.

- Use a matching installed skill when a request maps to its description.
- Treat skill instructions as workflow guidance; explicit user instructions take precedence.

- MySQL, MongoDB, and AWS MCP servers are installed disabled; enable them only after the required local credentials are configured.
